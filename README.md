**This repo is being updated continuously.

A mobile coffee shop application built in Kotlin for Android. The app lets users browse coffee categories, view popular products, and navigate through a cart-style shopping experience.

Access link: https://drive.google.com/file/d/1FSdlokHj0rSwPgcmBT9dPWXToWbj4JXF/view?usp=sharing

## Features
- Product browsing interface with categories and popular items
- RecyclerView-based layouts for dynamic product rendering
- Cart navigation flow
- Search bar UI and bottom navigation layout
- Image rendering with Glide
- Loading states for smoother user experience

## Tech Stack
- Kotlin
- Android SDK
- MVVM Architecture
- ViewModel
- RecyclerView
- ViewBinding
- Glide
- Gradle
